### 2.1 FL-06 真实失败与最小修复说明

`FL-06` 首次执行时确实暴露了真实失败点，但失败点属于**测试基线过时**而不是业务主链损坏：

1. Python 集成测试仍引用旧 crate 路径，例如：
   - `backend/crates/contracts` → 当前应为 `backend/crates/core/api-contracts`
   - `backend/crates/domain` → 当前应为 `backend/crates/core/domain-core`
   - `backend/crates/license` → 当前应为 `backend/crates/license-service`
   - `backend/crates/desktop/services` → 当前应为 `backend/crates/desktop-services`
   - `backend/crates/desktop/app` → 当前应为 `apps/desktop`
   - `backend/worker/license-worker` → 当前应为 `backend/worker/license-worker`
2. `test_security_runtime.py` 依赖可选 Python 包 `cryptography`，本地环境未安装。

本轮遵循“只在出现真实失败时再修复”的原则，仅做最小修复：

- 修正 `tests/integration/` 与 `backend/tests/` 下旧路径断言，映射到当前真实仓库结构；
- 将 `test_security_runtime.py` 中缺少 `cryptography` 的场景改为 `SkipTest`；
- 不修改任何 Rust/Tauri/Worker 业务逻辑。

风险点 & 应对策略
风险	影响	应对
Tauri 2.0 在 Windows 上 WebView2 兼容性	部分旧版 Windows 无 WebView2	打包时内嵌 WebView2 bootstrapper
security-core 的 C FFI 在 Tauri 中无用	低	直接调用 Rust 函数，不走 FFI，反而更简洁
desktop-services 当前是同步 trait	中	Phase 2 中将 trait 方法包装在 spawn_blocking 或进化为 async trait
视频号 API 可能需要 Cookie/登录态	中	adapters 层处理 Cookie 注入，前端提供配置入口
Tailwind v4 较新，生态尚在完善	低	回退方案：用 Tailwind v3

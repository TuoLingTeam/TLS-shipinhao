二、数据流图
用户点击"开始中差评查找"
  │
  ▼
Vue 组件 ReviewMatchPage.vue
  │ reviewStore.startReviewFind()
  ▼
Pinia reviewStore
  │ invoke('find_reviews', { days: 30, ... })
  ▼
Tauri IPC (自动序列化/反序列化 JSON)
  │
  ▼
#[tauri::command] async fn find_reviews(state, query)
  │ state.services.find_reviews(&query)
  ▼
desktop-services::DesktopServices.find_reviews()
  │ review_source.fetch_reviews()
  ▼
实际 ReviewSource 实现 (HTTP → 视频号 API)
  │
  ▼
返回 Vec<OrderMatchResult> → JSON → Vue 渲染表格
